## Major work shipped

1. **Photo recovery — visits**: rebuilt `recover_visit_note_photos_window2d.js`
   to query `visit.notes` (not `client.notes`) + skip pinned/location-level
   notes. With `--no-window` flag for historical backfill. Recovered 1,290
   photo_links across 56 newly-covered visits.
2. **Sandbox refresh preserves Yannick app columns**: snapshot+restore around
   the daily TRUNCATE so app-specific columns Yannick adds in Sandbox survive.
   Includes `public.`-qualified table names to dodge pg_dump's `search_path=''`.
3. **Truck attribution autopilot**: `derive_visit_vehicle_id.js` cross-references
   visit time+place against Samsara GPS pings to populate `visits.vehicle_id`.
   Runs hourly. See ADR 012.
4. **Tiered geocoding**: 199 → 437 properties geocoded via Jobber → Airtable →
   Samsara → Google fallback. ~$1.45 total cost. See ADR 013.
5. **Pre-sunset cleanup**: 17 hard-deleted test clients + 1 orphan property + 6
   soft-deleted borderline records. See migration `pre_sunset_cleanup_2026_05_04.sql`.
6. **3NF cleanup**: dropped `visits.truck`, `derm_manifests.manifest_images`,
   `derm_manifests.address_images` — all had 0 rows populated and either
   duplicated FK-resolvable data or were vestigial.
7. **Audit toolkit**: `scripts/probes/full_session_audit.js` runs cloud + local
   checks per Fred's standing instruction (run after every batch of fixes).
   Auto-refreshes Jobber token, flags DB size growth.
8. **Database use-case audit**: `scripts/probes/database_use_case_audit.js` —
   15 real-world queries from easy to complex, all green. Schema fit-for-purpose
   confirmed.
9. **Photo coverage audit**: `scripts/probes/photo_coverage_audit.js` — verifies
   coverage across visits / DERM / inspections.
10. **Lovable system prompt**: tightened from 12.5K → 9,976 chars to fit
    Lovable's Knowledge Base 10K cap. Added decision tree, refresh-aware schema
    rules, pinned-note rule, residential-client rule, inspection sync lag,
    `inspections_with_truck` JOIN guidance.
